## 2024-05-18 - [Fix Missing Authorization on Admin Endpoints]
**Vulnerability:** Several administrative and sensitive endpoints (e.g., `/api/analytics`, `/api/messages`, `/api/social-planner`, `/api/unsplash/search`, `/api/debug-env`) were missing the `verifyAdminToken` middleware, allowing unauthorized access to these routes.
**Learning:** In a CMS architecture where administrative tasks share the same backend as public content routes, it is critical that every new administrative or sensitive API endpoint is explicitly protected with an authentication middleware. The fallback should always be secure by default.
**Prevention:** Ensure that any newly created administrative endpoint, especially those under an admin scope (like `/api/messages`, `/api/social-planner`, `/api/analytics`), always includes the `verifyAdminToken` middleware. Implement centralized route grouping for admin APIs if possible to enforce middleware usage at the router level rather than per-route.
