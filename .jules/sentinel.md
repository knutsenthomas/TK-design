## 2024-03-20 - [Fix Host Header Injection in verifyAdminToken]
**Vulnerability:** The local development bypass for the `verifyAdminToken` middleware in `legacy_html/server.js` was relying on `req.hostname === 'localhost'`. The `Host` header can be easily spoofed by an attacker, leading to a Host Header Injection vulnerability that completely bypasses authentication for administrative API endpoints in environments where `req.hostname` wasn't overridden correctly or strictly validated.
**Learning:** `req.hostname` relies on the HTTP `Host` header, which is user-controlled and untrustworthy. Security mechanisms (like authentication bypasses) should never rely on the `Host` header to determine the source of a request.
**Prevention:** Always use `req.ip` or `req.socket.remoteAddress` to identify the originating IP address when attempting to enforce IP-based restrictions or local development bypasses. Verify against local IP addresses like `127.0.0.1`, `::1`, and `::ffff:127.0.0.1`.
