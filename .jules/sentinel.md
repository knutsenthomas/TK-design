## 2023-10-24 - Express Trust Proxy Misconfiguration & Admin Bypass
**Vulnerability:** The application was improperly reading the `x-forwarded-for` header for rate limiting and logging without configuring Express to trust the proxy, which could lead to IP spoofing. Additionally, some administrative API endpoints missed the `verifyAdminToken` middleware or were only partially covered by an overly specific `app.use` prefix boundary, potentially allowing unauthenticated access.
**Learning:** `app.set('trust proxy', 1)` must be explicitly set when running behind a proxy to ensure `req.ip` correctly resolves the client's IP. When applying middleware, explicit wildcard paths (`/api/social-planner/*`) should be used in `app.use` rather than relying on an exact prefix match for arrays.
**Prevention:** Configure Express with `app.set('trust proxy', 1)` and exclusively use `req.ip` for client IPs. Use explicit wildcards or apply `verifyAdminToken` directly to all administrative endpoint definitions.
